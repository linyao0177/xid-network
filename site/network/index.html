Flash a device

An ESP32-C3 board, Chrome or Edge, two minutes: install from the download page. The firmware joins this testnet. Then paste the device key it prints (BOAT|device …) here, and the testnet pays nodes to verify and store its readings.

Run a node

A Linux machine with Node.js 20+ and UDP open outbound. The installer prints the operator address; get test tokens for it below, then start the service.

curl -fsSL https://iot.xid.network/dl/node/install.sh | sudo sh -s -- \
  https://iot.xid.network/dl/node/boat-registry-0.1.0.tgz --testnet --no-start

No hardware

Simulated devices that sign readings the way the firmware does. The testnet sponsors each one it starts.

npm install -g https://iot.xid.network/dl/node/boat-registry-0.1.0.tgz
boat-sim --testnet --devices 3

Watch what your devices send: boat-watch --network xid-testnet --filter 'd/+/telemetry'
